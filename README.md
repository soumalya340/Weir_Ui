# weir

Next.js port of the weir demo UI — community-governed launchpad for utility tokens (propose, vote, raise, trade).

## Scripts

```bash
npm install
npm run build   # production build
npm test        # store + format unit tests
npm run dev     # local app (start only when you want to browse)
```

## Stack

Next.js 15 (App Router), React 19, Tailwind CSS v4, Zustand, Radix UI primitives, Sonner, Recharts.
